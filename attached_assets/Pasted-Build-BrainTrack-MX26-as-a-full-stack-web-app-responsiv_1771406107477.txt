Build “BrainTrack MX26” as a full-stack web app (responsive, mobile-first) using:
- Frontend: React + Tailwind
- Backend: Node/Express (or Next.js API routes) + PostgreSQL

- Auth: email + password (plus optional magic link)

CORE PRODUCT LOGIC
- Product: Brain Boost (MX26)
- Pricing:
  - MX26 Monthly Access: R169/month (auto-adjust to Nov 30, 2026)
  - MX26 Full Access (once-off): R1,299
- Contribution rules:
  - Monthly subscription: add R25 per active learner per month
  - Once-off: add 5.5% of once-off price (R1,299 * 0.055)
- Contributions are collected in checkout and recorded separately from subscription revenue.

Implement a payment orchestration layer that supports:
- Paystack (card/EFT options as supported)
- Yoco (card payments)
- Mobicred (buy-now-pay-later flow)

Create a unified interface:
- createCheckoutSession(provider, payload)
- verifyPayment(provider, reference)
- handleWebhook(provider, event)
- issueReceipt(transactionId)

Checkout must offer three payment method tiles:
1) Paystack
2) Yoco
3) Mobicred

Payment requirements:
- NEVER store raw card details (PCI compliance). Use provider hosted checkout or tokenization.
- Must support both:
  A) Monthly subscription (auto-adjusted remaining cycles)
  B) Once-off MX26 Full Access
- Webhooks must update transaction status reliably (idempotent).
- Receipts must reflect:
  - plan selected
  - contribution amount
  - MX26 end date rules if monthly
  - provider used
- Analytics must reflect revenue and contributions separately.

AUTO-ADJUSTED MONTHLY SUBSCRIPTION (MX26 END DATE)
- Window: Mar 1, 2026 → Nov 30, 2026
- Monthly purchase:
  - compute remaining months until 2026-11-30 inclusive
  - show checkout text: “You will be charged monthly for X remaining months until MX26 ends (30 Nov 2026). Billing stops automatically.”
  - Store:
    subscriptionStartDate, subscriptionEndDate=2026-11-30,
    remainingBillingCycles, autoStop=true
- Implement a scheduled job to:
  - charge monthly cycles through provider tokens where supported, OR
  - generate payment request each cycle and notify user if provider requires re-auth.
- Stop billing automatically at end date or when remainingBillingCycles reaches 0.
- After 2026-11-30: disable monthly and show “MX26 closed”.

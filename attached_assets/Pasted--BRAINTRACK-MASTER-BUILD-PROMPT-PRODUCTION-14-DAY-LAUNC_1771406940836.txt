==========================
SECURITY & EXAM INTEGRITY — STRICT
==========================

GENERAL PLATFORM RULES:
1) Disable copying:
   - block selection
   - block copy/cut/paste
   - block right click context menu
   - prevent drag copy

2) Disable downloads:
   - no PDF/image/downloads of protected content
   - only allow downloads for approved reward files if explicitly permitted

3) Screenshot detection + response:
   - detect common shortcuts where possible
   - blur content briefly + warning
   - log security event

4) Screen recording detection:
   - detect focus patterns / recording signals where possible
   - warn + log event

5) Watermark sensitive screens:
   - overlay learner id + timestamp on quizzes/exams/revision

6) Session monitoring:
   - tab switching
   - window focus loss
   - idle time
   - anomalies

Store all events in `security_events`.

EXAM MODE — LOCKDOWN RULES:
- fullscreen enforced
- copy/paste disabled
- right click disabled
- download disabled
- tab/window switching is a violation
- repeated focus loss is a violation

EXAM VIOLATION LOGIC:
If learner exits fullscreen OR switches tab/window OR attempts screenshot OR attempts copy/paste:
- immediately pause exam
- show modal: "Exam stopped. You violated the exam rules."
- mark exam status = terminated_due_to_violation
- log violation type + timestamp + learner id
- do not allow resume without parent/admin reset.

NOTE: Browser can’t fully prevent OS screenshots, so enforce detection + watermark + termination + audit logs.

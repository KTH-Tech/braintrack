Build a full-stack web platform called BrainTrack.

Purpose:
A CAPS-aligned South African learning platform focused on structured practice, mastery tracking, and performance improvement for learners (starting with Grade 12).

CRITICAL RULE:
All academic content must be CAPS aligned only.
Do NOT include international curricula, US syllabi, GCSE, IB, or generic topics.
Structure content strictly around CAPS:
Subject → Term → Topic → Subtopics → Exam-style questions.

Tech stack:
React + Tailwind CSS frontend
Node.js + Express backend
PostgreSQL database with Prisma ORM
JWT authentication with secure cookies

Brand & UI rules (mandatory):
- Inter font globally
- Body text always black (#000000) and same size
- H1 headings rainbow gradient
- Accent words use rainbow color rotation
- Buttons rainbow gradient with BLACK text
- Logged-in dashboards dark charcoal background with white cards
- Clean, modern, teen-focused but parent-trusted tone

User roles:
- learner
- parent (optional progress view)
- management_admin (internal analytics only)
- admin

Nova smart support agent:
- Visible only on logged-in pages

- Instant marking & feedback
- Progress mastery tracking

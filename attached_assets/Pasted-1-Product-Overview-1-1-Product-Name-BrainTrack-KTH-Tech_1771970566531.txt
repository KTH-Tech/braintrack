1) Product Overview
1.1 Product Name

BrainTrack™ (KTH Tech) — CAPS-aligned Grade 12 exam prep platform with adaptive learning, predictive insights, and gamified engagement.

1.2 Primary Goal

Improve Matric outcomes through:

CAPS-aligned content delivery

Exam-pattern-driven practice

Adaptive revision (spaced repetition/mastery learning)

Measurable progress visibility (learner/parent/school dashboards)

Engagement loops (streaks, XP, badges, coins, referrals)

1.3 Target Users

Learners (Grade 12) – primary user

Parents/Guardians – progress visibility + accountability

School Stakeholders – Principals, HODs, SGB – cohort visibility + outcome tracking

KTH Admin/Ops – content, onboarding, support, reporting

Distribution Partners – e.g., D6 / SMSWeb / WhatsApp funnel partners (limited access)

2) Scope
2.1 In Scope (V1)

Learner web/mobile web app (and later native iOS/Android, if required)

Content structure for Grade 12 CAPS subjects (focus on high-impact subjects first)

Nova bot “smart tutor” experience (guided help + troubleshooting + learning prompts)

Gamification: streaks, XP, badges, coins, referrals (with caps)

Payments + subscription access control

Dashboards: learner + parent + school

Support workflow via support@braintrack.app

Airtime/data vouchers as rewards (optional phase, later once compliance + vendor is confirmed)

4) User Journeys
4.1 Learner Journey (Happy Path)

Clicks onboarding link (D6/WhatsApp/referral/SMS)

Creates account → selects school (or “Not listed”)

Chooses subjects

Completes baseline quiz per subject

Receives recommended study plan

Starts practice (Exam Mode / Distinction Builder / Brain Boost)

Earns XP/coins → maintains streak

Uses Nova bot for help (explanations, next steps, motivation, troubleshooting)

Parent optionally linked for dashboard visibility

Subscription maintained; progress tracked weekly

4.2 Parent Journey

Learner invites parent via email/OTP link

Parent views dashboard: progress, streak, risks, recommended actions

Receives periodic progress prompts (optional notifications phase)

4.3 School Journey (Principal/HOD)

School registers (or KTH adds)

Principal/HOD views cohort dashboard

Sees adoption, practice rates, high-risk topics, predicted readiness

Downloads summary for SGB/parent evenings

5.5 Gamification

XP: awarded for completing sessions, accuracy, streak milestones

Coins: awarded for milestones + referrals (with strict caps)

Badges: streaks, mastery, consistency, “topic conquered”

Referral Rules (as per chat)

Learner refers a friend → R5 equivalent coins allocated

Cap: max 2 referrals per month earning rewards

Anti-abuse

Referral fraud detection:

Multiple accounts patterns

Phone/email reuse

Coins cannot be converted to cash (unless future voucher program is approved)

Coins redeemable for in-app perks only in V1 (e.g., unlock practice packs)

11) Acceptance Criteria (Examples)
Referrals

Given a learner shares a referral link, when a new user registers and activates, then referrer receives coins.

If referrer has already earned 2 referral rewards in current month, additional rewards are not issued.

Subscription Access

If subscription is inactive, premium modes are gated.

If payment webhook confirms renewal, access is restored within 60 seconds.

Nova

Nova must only provide CAPS-aligned learning guidance and must escalate to support for account/payment issues it cannot resolve.

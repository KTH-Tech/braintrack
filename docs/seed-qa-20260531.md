**Failure mode analysis**:
- ElevenLabs returns HTTP **401** with `code: "quota_exceeded"` (not 429 — it uses 401 for quota, 429 for rate-limit)
- `ttsElevenLabs()` only retries on 429/500/502/503/504 — 401 is non-retryable, so each topic fails immediately without a retry storm ✓
- `processJob()` catches the error, logs `FAIL topic=N ...`, returns `"failed"` — the loop continues to the next topic ✓
- The `writeFile` call is inside the `try` that catches TTS errors: if TTS fails, `writeFile` is never reached — **no partial/corrupt MP3s possible** ✓
- Accounting topics (which already had MP3s) were correctly **skipped** — idempotency confirmed ✓

### Route inventory

| Route | Method | Auth | Size limit | Description |
|-------|--------|------|-----------|-------------|
| `/api/topics/:id/voice-notes` | POST | ✅ `isAuthenticated` | 5 MB | Upload a webm/ogg/mp3/wav recording |
| `/api/topics/:id/voice-notes` | GET | ✅ `isAuthenticated` | — | List user's notes for a topic |
| `/api/voice-notes` | GET | ✅ `isAuthenticated` | — | All notes for user (with topic/subject join) |
| `/api/voice-notes/:id/file` | GET | ✅ `isAuthenticated` | — | Stream private audio file (ownership enforced) |
| `/api/voice-notes/:id` | DELETE | ✅ `isAuthenticated` | — | Remove note + file |

### Security checks passing

- `isAuthenticated` on every route — no public exposure of private recordings ✓
- Ownership enforced in stream route: `WHERE id=? AND user_id=?` — cannot stream another user's note ✓
- `Content-Type` validated by multer `fileFilter` (webm/ogg/mpeg/mp4/wav/aac/x-m4a only) ✓
- 5 MB cap enforced at multer `limits` — prevents oversized uploads ✓
- `Cache-Control: private, no-store` on stream response ✓
- File written to `uploads/audio/voice-notes/{userId}/note-{topicId}-{timestamp}.{ext}` — user-scoped directory ✓
- API response uses authenticated streaming URL (`/api/voice-notes/{id}/file`), never the raw disk path ✓

### Pipeline flow (code-verified)

```
POST /api/topics/:id/voice-notes
  → multer (memory storage, 5 MB cap, MIME filter)
  → validate topicId, check topic exists
  → mkdir uploads/audio/voice-notes/{userId}/
  → writeFile {filename}.{ext}
  → db.insert(voice_notes) → returns row
  → respond 201 { ...row, audioUrl: /api/voice-notes/{id}/file }
  → background: transcribeVoiceNoteInBackground() (Whisper — non-blocking)

GET /api/voice-notes/:id/file
  → isAuthenticated
  → db.select WHERE id=? AND user_id=?  (ownership enforced)
  → resolve absolute path
  → existsSync check (404 if missing)
  → set Content-Type + Cache-Control: private, no-store
  → createReadStream().pipe(res)
```
